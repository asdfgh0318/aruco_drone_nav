4. IMU correction + level subtraction

5. Body-frame offset NEGATE

Yaw Pipeline

1. solvePnP → rvec → R_cm = Rodrigues(rvec)
Rotation matrix: marker frame → camera frame
vision_gps.py:287
▼
2. Marker-to-world rotation marker_map.yaml
orientation: 0 → R_mw = [[1,0,0],[0,1,0],[0,0,1]]
Maps marker +X to world +X (North), marker +Z to +Z (Down)
vision_gps.py:273-278 — marker_to_world_rotation()
▼
3. Camera-to-body constant det = -1
R_CB_NOMINAL = [[-1,0,0],[0,1,0],[0,0,1]]
Reflection matrix (upward camera). Cannot use in rotation chains for IMU.
vision_gps.py (module-level constant)
▼
4. Body-to-world rotation
R_bw = R_mw @ R_cm.T @ R_CB_NOMINAL.T
vision_gps.py:290
▼
5. Extract yaw (compass heading)
yaw = atan2(R_bw[1,0], R_bw[0,0])
0 = North, +90 = East (NED compass convention)
vision_gps.py:291
▼
6. Degrees conversion
yaw_compass = degrees(yaw)
Already compass heading in NED (0=North, CW positive)
vision_gps.py:329
▼
7. Multi-marker fusion
yaw = atan2(Σ sin(yaw_i)*w_i, Σ cos(yaw_i)*w_i)
Circular weighted mean. Weights = 1/(distance + 0.1)
vision_gps.py:391-393
▼
8. Low-pass filter
yaw = prev + 0.3 * shortest_angle(new - prev)
Handles 0/360 wrap

▼
